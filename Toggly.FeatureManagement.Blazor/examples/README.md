# Artifact consumer example

`BlazorHost` restores the NuGet packages and compiles a minimal static SSR host.
Run `dotnet run --project BlazorHost` with your server-side TOGGLY_APP_KEY configured.

For four actual render modes, offline practice, public-key provisioning, all seven
workshop sections, and browser smoke tests, use the complete
[Blazor workshop](https://github.com/ops-ai/Toggly.Samples/tree/develop/blazor-sdk).
No local project dependency or vendored SDK is used by this consumer.
