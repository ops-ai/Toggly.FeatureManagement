## [1.0.0] - 2026-02-12

### Added
- Initial release of `@ops-ai/toggly-ga4-hook`
- Feature flag evaluation tracking via `afterEvaluation` hook
- Real-time feature flag change tracking via `afterRefresh` hook
- User identity tracking via `afterIdentify` hook
- Support for GA4 user properties
- Consent management integration
- Debug mode for development
- Custom event names and parameters
- Support for targeting specific GA4 measurement IDs
