# Toggly Remix SDK (deprecated)

> **Deprecated.** Use [`@ops-ai/react-router-toggly`](../Toggly.FeatureManagement.ReactRouter/react-router-toggly)
> for React Router 7/8 framework mode.

The `@ops-ai/remix-toggly-*` packages are no longer maintained. Last published
npm versions remain installable; they are not a living support line.

| Deprecated package | Replacement |
|--------------------|-------------|
| `@ops-ai/remix-toggly-core` | Inlined in `@ops-ai/react-router-toggly` |
| `@ops-ai/remix-toggly-client` | `@ops-ai/react-router-toggly/client` |
| `@ops-ai/remix-toggly-server` | `@ops-ai/react-router-toggly/server` |

See each stub package README under this directory for migration notes.
