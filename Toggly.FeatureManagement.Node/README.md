# Toggly Node.js SDKs

Official Node.js packages for [Toggly](https://toggly.io) feature flags, including framework adapters.

## Packages

| Package | Path |
|---------|------|
| `@ops-ai/toggly-node-core` | [`toggly-node-core`](toggly-node-core) |
| `@ops-ai/toggly-express` | [`toggly-express`](toggly-express) |
| `@ops-ai/toggly-fastify` | [`toggly-fastify`](toggly-fastify) |
| `@ops-ai/toggly-hono` | [`toggly-hono`](toggly-hono) |
| `@ops-ai/toggly-koa` | [`toggly-koa`](toggly-koa) |

## Install

```bash
npm install @ops-ai/toggly-node-core
# plus the adapter for your framework, e.g. @ops-ai/toggly-express
```
