# @ops-ai/react-native-toggly-storage-mmkv

MMKV storage adapter for React Native Toggly SDK. High-performance persistent
storage using `react-native-mmkv` 2 or 3.

## Install

```bash
npm install @ops-ai/react-native-toggly-storage-mmkv
```

## MMKV 4

MMKV 4 uses Nitro and changed the factory and deletion APIs. Install
`@ops-ai/react-native-toggly-storage-mmkv4` for that generation. It keeps the
same Toggly storage keys, ID, and encryption options while this package remains
available for MMKV 2 and 3 applications.
