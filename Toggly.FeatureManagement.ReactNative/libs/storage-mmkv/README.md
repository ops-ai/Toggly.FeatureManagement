# @ops-ai/react-native-toggly-storage-mmkv

MMKV storage adapter for React Native Toggly SDK. High-performance persistent storage using react-native-mmkv.

## Install

```bash
npm install @ops-ai/react-native-toggly-storage-mmkv
```
